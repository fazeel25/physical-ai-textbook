# Physical AI & Embodied Intelligence

Physical AI is the engineering of intelligence that must succeed under gravity, latency, uncertainty, limited energy and real human consequences. This book takes you from that first principle to a complete autonomous mobile-manipulation capstone.

## Who this book is for

- Students entering robotics, AI or mechatronics
- Software engineers moving from screens to machines
- Researchers who want one map across control, learning and foundation models
- Builders who learn best by running simulations before buying hardware

## The learning loop

Every chapter uses the same five-step rhythm:

1. **Model** the physical problem and its assumptions.
2. **Simulate** the system before touching hardware.
3. **Measure** behavior with explicit metrics.
4. **Transfer** the smallest proven behavior to a real or edge target.
5. **Reflect** on failure modes, safety and evidence.

> A video of a robot succeeding once is a demonstration. A repeatable metric with documented failure cases is engineering evidence.

## Suggested setup

Use Ubuntu 22.04 or newer, ROS 2, Python 3.10+, Git, Docker, Gazebo and a code editor. GPU-heavy Isaac Sim chapters can be read without a GPU; the lab gives a lighter simulation alternative.

| Part | Outcome |

| I. Foundations | Explain how bodies, sensors and environments shape intelligence |
| II. Robot stack | Build ROS 2 nodes, robot models and transforms |
| III. Simulation | Create testable worlds and synthetic data pipelines |
| IV. Learning | Train policies from reward, demonstrations and language |
| V. Deployment | Run accelerated perception and coordinated autonomy |
| VI. Safety & capstone | Evaluate a human-centered autonomous system |
