# Physical AI & Embodied Intelligence

An open, simulation-first textbook for students, engineers and researchers building intelligent machines. It contains 18 chapters across six parts, hands-on labs, knowledge checks, progress tracking and a complete mobile-manipulation capstone.

## Run locally

```bash
npm install
npm start
```

Build the production site:

```bash
npm run build
npm run serve
```

## Curriculum

1. Physical AI
2. Embodied Intelligence
3. Sensors & Perception
4. ROS 2 Foundations
5. URDF & Robot Models
6. TF & Kinematics
7. Gazebo Simulation
8. Unity for Robotics
9. Digital Twins & Synthetic Data
10. Reinforcement Learning
11. Imitation Learning
12. Vision-Language-Action Models
13. Isaac Sim & Isaac ROS
14. Edge Deployment
15. Multi-Agent Robot Systems
16. Human-Robot Interaction
17. Safety & Evaluation
18. Capstone: Autonomous Mobile Manipulator

## Deployment

Push to `main`. The included GitHub Actions workflow builds the Docusaurus site and publishes it to GitHub Pages.
